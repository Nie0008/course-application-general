# 03 课程体系与多层材料设计

**输入**：实际开课大纲、对象与学情、课程目标、资源清单、已有结构和版本。

**执行**：
1. 为课程目标写可观察行为与成果标准；先设计学生需要交什么，再确定学习顺序与资源。
2. 建立“目标—模块—单课—任务—评价—证据”映射，每个目标必须有学生行为和检查方式。
3. 分层生产：L1申报定位；L2全课结构；L3模块递进；L4单课流程；L5可讲述讲稿与课件。层级是本工作包的组织方法，不是官方栏目。
4. 用内容主表管理课程编号、标题、对象、前置能力、目标、核心方法、任务产物、评价、正式学时、微课分钟、资源状态。正式学时和微课资源时长分别汇总。
5. 区分教师视频演示、学生课堂实操、课后项目：每类有自己的时间和完成标准。先演示过某工具，后续课可引用并升级任务；不必为了“去重复”删掉必要练习。
6. 价值目标转成任务中的可观察选择与判断，并说明评价方式；内容和标准依据当前课程确定。

**产出**：结构主表、目标任务评价矩阵、模块设计、单课脚本框架、大纲差异清单。

**检查**：按每条记录的实际单位和时长逐项汇总；目标不超出学生前置基础；不同文档“实操”含义一致；规划资源不写成已运行。

**可复制指令**：
> 以真实大纲为边界，建立目标、模块、单课、学生任务、评价证据的映射。分别统计正式学时和线上资源分钟。先输出课程内容主表与一个代表性单课的L4框架，再按依赖细化讲稿和课件。发现旧版与新版数量冲突时保留双方来源，核清对象后处理。
