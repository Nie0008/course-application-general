# 07 说课、PPT与视觉资产

**输入**：当次说课要求、申报书主稿、事实词典、已有配图、口播时长与出镜要求。

**执行**：
1. 用一条论证线串起课程问题、设计、方法、创新和成效；每页只承担一个关键论点并给对应证据。
2. 建立页码—主张—口播—画面—来源—时长表，再生成PPT。申报书正式文字转口语时保持事实强度，不增加“显著”“领先”等无来源形容。
3. 区分教师讲解、素材播放、屏幕演示与静默停顿；画面和旁白重叠播放的时间只算一次。字数只能估时，试讲才测量实际时间。
4. 方法图用关系表达机制；流程图突出师生动作和观察证据；数据图标明原题、分母、时点。图片、图谱数量不证明教学有效。
5. 沿用用户认可样式；印刷图与投影图分别检查可读性。需要后续修改的图保留可编辑源；PPT文字可编辑性要实际检查，不能只交整页位图。
6. 草稿、可编辑源与展示预览分开放置，输出目录按当前项目约定。

**产出**：说课稿、分镜表、PPT及预览、可编辑图源、引用记录。

**检查**：文字与图一致；现场可读；字体与裁切正常；口播不超时；正式数据图和示意图标识明确。

**可复制指令**：
> 从已核实申报书提炼【规定时长】说课稿，并制作逐页分镜表。每页写论点、证据、讲述与画面。核对所有数字及框架名称；区分口播估时和试讲实测。配图按已有样式，交可编辑源和预览，模拟图显著标识。
