# 06 申报书与创新表述

**输入**：本次表格、字数限制、事实台账、教学机制、证据索引、建设计划。

**执行**：
1. 逐栏建立问题：课程面向谁、解决什么、如何组织、怎样评价、有什么证据、下一步建什么。先分配事实与证据，后组织文字。
2. 论证按“教学问题—具体做法—实施载体—可观察变化—证据”展开；没有效果证据时写做法与待验证目标，不写已显著提升。
3. 特色表达课程的可辨识特点；创新解释改变了原有教学方式的什么，以及怎样发生作用。使用“教学做法—具体载体—教学价值”组织可粘贴分点说明。
4. 已有框架建立词典，固定名称、定义、适用层次、课堂载体，避免申报书、说课和代表课各造一套词。新课可不使用任何数字化模式名称。
5. 成果分课程直接成果、团队历史基础、校外认可；课程前身获奖不能写成新课程已获奖。申报/立项/结项分别描述，推广、培训、实际付费也分别取证。
6. 建设计划写行动、责任、时间、产物和核验方式。统计正文字符并报告计数口径，最后以官方系统计数为准；不填不存在的事实凑字数。

**产出**：分栏正文、主张证据表、待填字段、超字数与冲突清单。

**检查**：没有模板残留指令、占位数字或计划冒充成果；同一数字附对象和时间；每个强结论有相应证据。

**可复制指令**：
> 按本次申报书栏目与字数限制写可直接粘贴的正文。沿用已确认框架，每项创新写清做法、课堂载体与教学价值。另附主张—证据对照表。没有证据的数字、因果、获奖和推广成效保留待核，正文不把未来建设写成已完成。
