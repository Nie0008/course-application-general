# course-application｜课程申报协作 Skill

帮助课程团队把政策要求、真实课程基础和教学证据转成相互一致的申报材料。可以完成一个环节，也可以按项目需要贯穿课程建设、申报书、说课、实录及佐证组包。

它提供方法和空白模板。申报资格、当次类别、期限与教学成效都需从使用者提供的原件重新核实。

## 可以用来做什么

- 逐句读通知，辨认主体、适用范围、限定和例外，区分原意、推断与建议。
- 将政策导向与课程基础匹配，找到有教学机制和证据路径的切入点。
- 核查区域需求、公开政策与课程的关系，将适配内容转成具体学习任务。
- 分别研究同行对标、获批案例和本轮竞争，保留来源与未知。
- 设计课程、代表课和项目任务书，检查目标、学生行动、成果与评价的对应关系。
- 写申报书、说课与方法图，核对版本、数字、课堂实施和提交状态。

入口是 [SKILL.md](SKILL.md)。11 份任务指南位于 `references/`，16 份空白模板位于 `assets/`。

## 在 Codex 中安装和使用

克隆到默认 Skill 目录；已存在同名目录时先保留旧版，另选位置检查，避免覆盖。自定义了 Codex 目录的用户应使用自己的 `skills` 路径。

```bash
git clone https://github.com/Nie0008/course-application-general.git ~/.codex/skills/course-application
```

在能够访问课程资料的任务中调用，例如：

```text
请使用 $course-application 逐句读我提供的本次申报通知。
保留原文位置，区分明确要求、支持方向和不能推出的结论。
再与本课大纲及已有材料对照，提出候选切入点和证据缺口。
本轮先完成解读和匹配，暂不批量写申报书。
```

需要新建工作目录时可运行：

```bash
python3 ~/.codex/skills/course-application/scripts/init_project.py ~/course-application-work
```

脚本仅使用 Python 标准库，复制空白模板、创建工作子目录，保留同名已有文件；它不提取资料、不生成事实，也不执行外部提交。接续已有项目可直接沿用原台账，无需重新初始化。

其他支持 `SKILL.md` 的工具可按其安装机制使用本目录；本仓库未验证各工具的自动加载、调用或完整申报效果。

## 公开包与工作资料

本仓库只包含通用方法、空白模板和初始化脚本，没有已填写的课程、类别、地域或政策案例。安装后，实际项目的原件、课程属性、统计数据与运行台账保存在使用者自己的工作目录中，不写回本仓库。

使用时按 [来源记录方法](references/sources.md) 核对当次原件。资格、类别、期限和证据均以本次输入为准；生成文件和格式通过不代表课程已实施、提交或获评。真实上传、发送和公开资料应有使用者对具体对象的授权。
